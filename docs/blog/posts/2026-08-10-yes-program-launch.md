# The YAML Company Launches Enterprise Sustainability (YES) Program to Secure Core YAML Infrastructure

**SEATTLE, WA — August 10, 2026** — The YAML Company (YAML LLC) today announced its updated mission and the launch of the YAML Enterprise Sustainability (YES) program. Designed to add professional stewardship to the YAML core libraries (YAML Family), the initiative promises cross-library remediation, supply chain security, and enterprise-grade compliance.

Led by YAML co-creator Ingy döt Net, YAML LLC introduces commercial stewardship to resolve cross-library technical debt, harden supply chain security, and bring the community together to plan YAML’s future.

<!-- more -->

With over 98% of enterprises adopting cloud-native technologies and 82% deploying Kubernetes in production, YAML serves as the primary declarative configuration layer for modern cloud deployment [[CNCF Annual Cloud Native Survey](https://www.cncf.io/reports/the-cncf-annual-cloud-native-survey/)]. However, key libraries—including `libyaml`, `go-yaml`, `PyYAML`, and `yaml-serde`—share code lineage from the original PyYAML codebase. This shared lineage has led to cross-library specification drift and systemic vulnerabilities.

### Key Offerings & Program Details

To address these challenges, The YAML Company is introducing coordinated community resources alongside enterprise support:

*   **Centralized Roadmaps & Security:** Public release schedules, compliance reports, and security advisories will be available at [github.com/yaml](https://github.com/yaml).
*   **Open-Source Governance:** Core updates, pull requests, and the forthcoming *YAML Family Contributor Handbook* are managed via [github.com/yaml](https://github.com/yaml).
*   **Interactive Testing Environment:** The multi-library testing platform at [play.yaml.com](https://play.yaml.com) allows developers to verify cross-language parsing compliance.
*   **YAML Enterprise Sustainability (YES) Program:** Designed to help enterprises meet EU Cyber Resilience Act (CRA) standards, the YES program offers support and access to managed, compliant builds.
